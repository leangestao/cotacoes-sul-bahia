# Cotações Sul da Bahia

Cotações diárias de gado (bezerro, boi gordo) e cacau para Ibirapitanga e região, atualizadas em dias úteis.

- `cotacoes.json` — histórico diário (mais antigo primeiro). Campos ausentes = sem publicação da fonte no dia.
- `widget.html` — bloco para colar no widget "HTML" do Elementor (WordPress).

Fontes: gado — Scot Consultoria e Cepea/Esalq, via Notícias Agrícolas; cacau (Ibirapitanga e Bolsa de Nova York) — Preço do Cacau (precodocacau.com.br). Valores de referência estadual/regional; o preço de cada negócio varia com peso, padrão e frete.
